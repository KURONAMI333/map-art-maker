# Map Art Maker

画像の URL を貼るか、画像ファイルをブロックの画面にドラッグ&ドロップすると、普通の地図として持てる・飾れるロック済みの地図アートになる。

バニラの地図は地形しか映さない。このMODは、好きな画像をロック済みの完成地図に変えるクラフト可能なブロックを追加する。壁に1枚だけ飾ってもいいし、複数枚をまとめて壁画にしてもいい。管理者権限もランチャー用プラグインも要らない。ただのブロックとレシピで、サバイバルで使える設計。

**できること**

- 画像の URL を貼る、またはローカルの画像ファイルをブロックの画面にドラッグ&ドロップする。どちらの方法でも作れる
- 1×1 から 3×3（最大9枚）までのグリッドを作って壁画にできる
- 作成前にディザの on/off を切り替えられる
- 出力1枠につき空の地図を1枚消費する
- ブロックは上/横から空の地図を入れられ、下からはホッパーで完成品を吸い出せる。大量生産を手作業で見張らなくていい
- 完成した地図はロックされる（製図台でガラスを使ってロックするのと同じ仕組み）。持ち歩いても本物の地形で上書きされない
- マルチプレイ対応: 完成した地図はサーバー側に保存されるので、誰が拾っても同じ絵が見える

**使い方**

1. Map Art Maker ブロックをクラフトする（棒3 + 板材5 + 空の地図1、製図台と同じ配置）。
2. 空の地図を入力枠に入れ、画像の URL を貼るか画像ファイルを画面にドロップする。
3. グリッドサイズ（1×1〜3×3）を選んで Create を押す。完成した地図は自分で取り出すか、ホッパーに任せる。

**サーバー管理者向け**

URL を使うときに取りに行くのはサーバーなので、loopback・LAN・クラウドのメタデータアドレスは既定で拒否される。プレイヤーが内部ネットワークを探らせることはできない。意図的にプライベートネットワーク上の画像を使いたい場合だけ、設定で開けられる。

**このバージョンに無いもの**

- クリップボードからの画像貼り付けには対応していない。対応しているのは URL の貼り付けとファイルのドロップのみ
- ディザは on/off の切り替えのみで、アルゴリズムの選択肢は無い
- 完成した地図を額縁へ自動で設置する機能は無い（自分で設置する）
- 作成済みの地図アートの編集・削除機能は無い
- Create の contraption 対応は無い

クライアント・サーバーの両方に導入が必要。他 MOD への依存は無し。
